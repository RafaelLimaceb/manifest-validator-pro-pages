## Como o Chrome Web Store enxerga

A loja exige que o link de Política de Privacidade aponte para uma **página dedicada** com o texto
real da política. Este repositório entrega exatamente isso, num domínio `*.github.io` que é
considerado válido pelo Google.

## Habilitar GitHub Pages

1. Vá em **Settings &rarr; Pages** do repositório.
2. Em *Build and deployment*, selecione:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` e pasta `/ (root)`
3. **Save**. Após ~1 min a página ficará publicada em `https://SEU_USUARIO.github.io/manifest-validator-pro-pages/`.

> Certifique-se de que o repositório é **público** e que o GitHub Pages está **Enviado** (não Drafth).
> O status aparece em Settings &rarr; Pages.
